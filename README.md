# Juego de Truco en Python

## Descripción
Proyecto universitario desarrollado en Python que consiste en la implementación del juego de Truco, incorporando la lógica del juego, la gestión de cartas, el seguimiento de puntajes y la interacción entre jugadores.

## Tecnologías utilizadas
- Python.
- Programación estructurada.
- Gestión de datos y estructuras de datos.

## Proyecto académico
Desarrollado en el marco de la formación universitaria, aplicando conceptos de programación, organización de código, resolución de problemas y diseño de funcionalidades.
